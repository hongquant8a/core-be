================================================================================
BE CHANGELOG — 2026-05-15 — Agenda flag `allow_vote_registration`
================================================================================

TÓM TẮT
─────────
Chương trình họp (meeting_agendas) bổ sung flag `allow_vote_registration`
(pattern giống `allow_discussion_registration` + `allow_question_registration`).

Khi flag = true → chương trình này có biểu quyết. Vote topic gắn vào agenda
qua FK `meeting_vote_topics.meeting_agenda_id` (đã có sẵn) → admin biết
biểu quyết thuộc chương trình nào.


────────────────────────────────────────────────────────────────────────────────
A. SCHEMA
────────────────────────────────────────────────────────────────────────────────
Migration: 2026_05_15_100611_add_allow_vote_registration_to_meeting_agendas
  meeting_agendas.allow_vote_registration  (BOOLEAN default false)

KHÔNG có cột `vote_duration_minutes` ở agenda level — duration của từng phiên
biểu quyết lấy từ `meeting_vote_topics.duration_minutes` (1 topic 1 duration
riêng).


────────────────────────────────────────────────────────────────────────────────
B. REQUEST BODY (Store + Update agenda)
────────────────────────────────────────────────────────────────────────────────
POST/PUT/PATCH /api/meeting-agendas (+ /api/meetings/{meeting}/agendas/* nested)

  body: {
    ...
    "allow_discussion_registration": true | false,     // đã có
    "discussion_duration_minutes": 30,                 // đã có
    "allow_question_registration": true | false,       // đã có
    "question_duration_minutes": 15,                   // đã có
    "allow_vote_registration": true | false            // ← NEW
  }

Validation: nullable | boolean.

────────────────────────────────────────────────────────────────────────────────
D. FE FLOW
────────────────────────────────────────────────────────────────────────────────
1. Form tạo/sửa chương trình họp (Tab Admin chỉnh sửa cuộc họp):
   - Bổ sung checkbox "Cho phép biểu quyết" → bind tới `allow_vote_registration`.
   - Khi tick → mở UI tạo vote-topic kèm theo (gọi `POST /api/meeting-vote-topics`
     hoặc `POST /api/meetings/{meeting}/vote-topics` với `meeting_agenda_id =
     agenda.id`).

2. Tab Điều hành / Chủ trì — filter danh sách bên trái theo cờ của agenda đang
   chọn:
   - `agenda.allow_discussion_registration` → show panel "Quản lý thảo luận".
   - `agenda.allow_question_registration` → show panel "Quản lý chất vấn".
   - `agenda.allow_vote_registration` → show panel "Quản lý biểu quyết".
   - Nếu agenda chỉ có 1 cờ → ẩn 2 panel còn lại.

3. Tab Màn chiếu: tương tự, render section phù hợp loại agenda.
