================================================================================
BE CHANGELOG — 2026-05-15 — Chuẩn hóa style Excel export (BaseExport)
================================================================================

TÓM TẮT
─────────
Toàn bộ Excel export trong dự án giờ tuân theo 1 chuẩn style chung qua base
class `App\Modules\Core\Exports\AbstractExcelExport`.

Mục tiêu: file Excel xuất ra đồng nhất, đẹp, đúng tone công văn nhà nước
(font Times New Roman, header tone xanh đậm, border, freeze pane).


────────────────────────────────────────────────────────────────────────────────
A. STYLE CHUẨN (mọi export đều áp dụng)
────────────────────────────────────────────────────────────────────────────────
- Font:        Times New Roman 11
- Header row:  bold, fill #1F4E78 (xanh đậm), chữ trắng, center, wrap text,
               row height 28
- Data rows:   vertical center, wrap text
- Border:      thin (#999999) full toàn vùng có data
- Cột:         auto-size theo nội dung
- Freeze:      row 1 (header pinned khi scroll)
