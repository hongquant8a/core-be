────────────────────────────────────────────────────────────────────────────────

Toàn dự án: 13 export class kế thừa AbstractExcelExport tự động hưởng. Cột
nào có header chứa keyword "STT", "Trạng thái", "Thời gian" (case-insensitive,

  - Cột "Chương trình", "Nội dung", "Người đăng ký" → left (default)

2. FILENAME EXCEL — THÊM TIMESTAMP HH-mm-ss_dd-MM-yyyy
────────────────────────────────────────────────────────────────────────────────

Convention mới:
  export__{slug}_HH-mm-ss_dd-MM-yyyy.xlsx

Ví dụ:
  export__thao-luan-hop_15-30-45_18-05-2026.xlsx
  export__dai-bieu-hop_15-30-45_18-05-2026.xlsx
  export__nguoi-dung_15-30-45_18-05-2026.xlsx

Mục đích: tránh đè file khi tải nhiều lần + audit dễ.

Phạm vi đổi: TOÀN BỘ endpoint export Excel của dự án (Core 6 + TaskAssignment 5
+ Meeting 7 = 18 endpoint). Filename trả qua header Content-Disposition.

FE action:
  - Nếu FE đọc filename từ response header Content-Disposition (cách chuẩn) →
    không cần đổi gì, browser tự tải đúng tên mới.
  - Nếu FE hardcode filename mong đợi (vd kiểm tra response chứa "export__
    thao-luan-hop.xlsx") → CẦN sửa. Format giờ luôn có timestamp.

5. EXPORT THẢO LUẬN / CHẤT VẤN — TÁCH 2 ROUTE (full / mine)
────────────────────────────────────────────────────────────────────────────────

In-meeting endpoint nên gate qua Policy (FK pure), KHÔNG Spatie permission.
Tách 2 endpoint riêng cho 2 ngữ cảnh:

5.1 EXPORT FULL (chair/op):
  GET /api/meetings/{meeting}/discussion-registrations/export
  Gate: can:operate,meeting  (chair/op của meeting, FK pure, KHÔNG admin
                              Spatie fallback)

  Query params:
    type              string   required   discussion | question
    meeting_agenda_id integer  optional   ID chương trình họp

  Filename: export__thao-luan-hop_HH-mm-ss_dd-MM-yyyy.xlsx
            export__chat-van-hop_HH-mm-ss_dd-MM-yyyy.xlsx

  Trả về toàn bộ đăng ký trong meeting (theo type + agenda filter).

5.2 EXPORT-MINE (đại biểu / chair / op tự xuất của mình):
  GET /api/meetings/{meeting}/discussion-registrations/export-mine
  Gate: can:participate,meeting  (user có role bất kỳ trong meeting)

  Query params:
    type              string   required   discussion | question
    meeting_agenda_id integer  optional   ID chương trình họp

  Filename: export__thao-luan-hop-cua-toi_HH-mm-ss_dd-MM-yyyy.xlsx
            export__chat-van-hop-cua-toi_HH-mm-ss_dd-MM-yyyy.xlsx

  Service filter `participant.attendee.user_id = auth user.id` — chỉ trả đăng ký
  của user đang login. Chair/op gọi endpoint này cũng chỉ thấy đăng ký riêng họ
  (chair/op có thể có đăng ký với vai trò đại biểu).

DROP:
  - Cũ route gate `exportReports` với Spatie fallback admin.
  - Đề xuất `?my=true` query trên cùng endpoint (đổi sang 2 route riêng cho
    minh bạch).

Tại sao tách 2 route:
  - Gate clear cho mỗi route, không cần controller conditional.
  - FE hiển thị 2 nút riêng (Xuất tất cả vs Xuất của tôi) → call 2 URL khác.
  - Pure Policy gate, không lẫn Spatie permission.

FE action:
  - Tab Thảo luận / Chất vấn:
    * Nút "Xuất tất cả" (chỉ chair/op thấy/click được — gọi /export). Đại biểu
      KHÔNG thấy nút này (BE 403).
    * Nút "Xuất đăng ký của tôi" (đại biểu / chair / op đều thấy — gọi
      /export-mine).
  - URL gốc /export không còn nhận ?my=true; xóa logic cũ nếu có.
