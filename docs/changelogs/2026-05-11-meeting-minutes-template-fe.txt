CHANGE LOG FE — Template biên bản họp (.docx) + xuất biên bản
Ngày: 2026-05-11

TÓM TẮT
Admin upload file .docx có placeholder ${var_name} làm template. Khi user (chair/operator
của meeting) bấm "Xuất biên bản" → BE replace placeholder bằng data thật và trả file .docx
generated.

Template KHÔNG scope theo organization — per module Meeting, mọi org dùng chung. Hệ thống
có 1 template "mặc định" (is_default=true).

ENDPOINTS

1) Cheatsheet biến template (FE hiển thị cho người soạn template)
   GET /api/meeting-minutes-templates/variables
   - Auth-only, không cần permission đặc biệt.
   - Trả schema { scalar: {...}, tables: {...} }.

   scalar: object {key: 'mô tả tiếng Việt'} — vd
     { "meeting_title": "Tiêu đề cuộc họp",
       "dia_diem_hop": "Địa điểm họp",
       "chu_toa": "Họ tên chủ tọa",
       "tong_dai_bieu": "Tổng số đại biểu",
       "ty_le_co_mat": "Tỷ lệ có mặt (%)",
       ... }
     Người soạn .docx chèn ${meeting_title}, ${dia_diem_hop}, ... vào nơi cần thay thế.

   tables: object {table_name: { description, columns: {col_key: 'mô tả'} } }
     Mỗi table = 1 bảng lặp dòng. Người soạn tạo bảng trong Word, ở 1 row mẫu đặt placeholder
     theo các col_key. BE sẽ clone row đó theo số records và replace từng row.
     6 table groups:
       - agenda      (Chương trình họp)
       - participant (Thành phần dự họp)
       - absence     (Vắng mặt)
       - discussion  (Thảo luận)
       - question    (Chất vấn)
       - vote        (Biểu quyết)

2) CRUD template (admin)
   GET    /api/meeting-minutes-templates                  (permission: meeting-minutes-templates.index)
   GET    /api/meeting-minutes-templates/{id}             (.show)
   POST   /api/meeting-minutes-templates                  (.store) — multipart: name, description, file, is_default, status
   PUT    /api/meeting-minutes-templates/{id}             (.update)
   POST   /api/meeting-minutes-templates/{id}             (.update — multipart, dùng cho upload file mới)
   DELETE /api/meeting-minutes-templates/{id}             (.destroy)

   - file: .docx (mimes:docx, max 10MB).
   - is_default=true -> các template khác tự động set false.

3) Xuất biên bản từ template
   POST /api/meetings/{meeting}/export-minutes
   Body JSON: { "template_id": 1 }
   - Auth-only, KHÔNG cần Spatie permission.
   - Gate qua MeetingPolicy::operate (chair OR operator của meeting đó). Super Admin bypass.
   - Response: file .docx (Content-Type: application/vnd.openxmlformats-officedocument.wordprocessingml.document).
     FE: const url = `/api/meetings/${id}/export-minutes`; -> POST với body { template_id } -> blob download.

QUY TRÌNH FE

Tab "Cài đặt biên bản" (admin):
  1. Show CRUD list template + button "Thêm mới".
  2. Form thêm: name, description, is_default, status, file upload (.docx only).
  3. Show button "Tải template hiện tại" để admin chỉnh sửa file đã upload.
  4. Show button "Xem cheatsheet biến" -> mở modal hiển thị data từ /variables endpoint
     (scalar variables + tables variables với cú pháp người dùng cần chèn vào Word).

Tab "Xuất biên bản" (trong màn meeting, chỉ chair/operator thấy):
  1. Dropdown chọn template (fetch /meeting-minutes-templates?status=active).
     Mặc định pre-select template có is_default=true.
  2. Button "Xuất biên bản" -> POST /api/meetings/{id}/export-minutes body { template_id }.
  3. Nhận response blob -> trigger download file.

CÚ PHÁP PLACEHOLDER TRONG .DOCX

- Scalar: gõ ${var_name} ở vị trí muốn thay thế.
  Vd: "Địa điểm họp: ${dia_diem_hop}"

- Table row: trong Word tạo bảng có header tùy ý. Tạo MỘT row mẫu (sẽ được BE clone). Trong
  row mẫu, đặt placeholder dùng col_key của bảng tương ứng:
  Vd cho table agenda:
    | STT     | Nội dung           | Người trình bày    | Thời gian (phút)   |
    | ${stt}  | ${agenda_content}  | ${agenda_person}   | ${agenda_duration} |
  BE sẽ clone row đó theo số agenda records, mỗi clone replace 1 record.

QUY TẮC RENDER NHANH

- Nếu template không có 1 placeholder nào đó -> BE silently bỏ qua (không lỗi).
- Nếu meeting không có data cho 1 table (vd không có thảo luận nào) -> row mẫu sẽ bị xóa
  hoàn toàn (clone(0)).
- ballot_mode = anonymous KHÔNG áp dụng cho biên bản (biên bản chỉ ghi nhận tổng phiếu,
  không liệt kê tên người vote). Anonymize chỉ áp dụng cho /meeting-vote-responses/export.
