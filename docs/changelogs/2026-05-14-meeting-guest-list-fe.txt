────────────────────────────────────────────────────────────────────────────────
C. MEETING — PAYLOAD GUESTS INLINE
────────────────────────────────────────────────────────────────────────────────
POST + PUT/PATCH /api/meetings nhận thêm field `guests` (array of objects):

  {
    ...
    "guests": [
      {
        "name": "Nguyễn Văn A",            // required
        "position_name": "Giám đốc",       // optional
        "phone": "0901234567",             // required
        "email": "a@example.com",          // required
        "zalo_user_id": "1234567890",      // optional — nếu nhập, gửi cả Zalo OA
        "organization_name": "Sở Y tế"     // optional
      },
      {
        "id": 12,                          // optional — nếu có thì update existing
        "name": "Trần Thị B",
        "phone": "0907654321",
        "email": "b@example.com"
      }
    ]
  }

Logic BE sync:
  - Item có `id` thuộc meeting hiện tại → UPDATE record.
  - Item không có `id` → CREATE record mới + tạo invitation pending.
  - Existing guest không có trong list → DELETE record (cascade xóa invitation).

POST: nếu omit field `guests` hoặc gửi `[]` → không tạo guest.
PUT/PATCH:
  - Omit field `guests` → giữ nguyên list hiện tại (không sync).
  - Gửi `guests: []` → xóa toàn bộ guest của meeting.

E. GỬI THƯ MỜI — KHI MEETING PUBLISH
────────────────────────────────────────────────────────────────────────────────
Event `MeetingPublished` → listener `SendMeetingPublishedNotifications` (queued)
iterate invitation pending. Cho mỗi invitation có `meeting_guest_id`:

  Build inline payload từ contact info của guest:
    - subject: "Mời tham dự cuộc họp: {title}"
    - body HTML/text: "Kính gửi {name}, Bạn được mời tham dự cuộc họp: {title}.
                       Thời gian: {start_time}."
  Channels (theo config notification module Meeting):
    - Mail:    gửi nếu guest.email không null.
    - SMS:     gửi nếu guest.phone không null.
    - Zalo OA: gửi nếu guest.zalo_user_id không null (admin tự nhập).
    - FCM:     SKIP (guest không có device token).
  Sau gửi: invitation.status = 'sent', sent_at = now().
