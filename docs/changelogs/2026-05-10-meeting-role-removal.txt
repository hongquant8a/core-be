CHANGE LOG — Meeting role removal (2026-05-10)
==================================================

CONTEXT
- Bỏ role Spatie "Thư ký họp" + "Đại biểu họp" trong module Meeting.
- Thay bằng 1 role generic "Đại biểu" với full quyền API ở các sub-resource trong meeting.
- FE check render dựa vào FK: chairperson_meeting_attendee_id / operator_meeting_attendee_id
  + participants list, không dựa vào Spatie role.

  Admin / Quản trị giữ.

DEPLOY
1. git pull
2. composer install --no-dev --optimize-autoloader
3. php artisan migrate --force         # chạy migration cleanup role legacy
4. php artisan db:seed --class=MeetingPermissionSeeder --force   # seed role mới + perm
5. (optional) php artisan db:seed --class=MeetingDataSeeder --force   # nếu cần re-seed data sample
6. php artisan config:cache
7. php artisan route:cache
8. php artisan queue:restart            # noti job pickup code mới
9. sudo /etc/init.d/php-fpm-83 reload   # OPcache invalidate
