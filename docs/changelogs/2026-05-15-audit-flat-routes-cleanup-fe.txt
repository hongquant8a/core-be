================================================================================
BE CHANGELOG — 2026-05-15 — Audit cleanup: DROP 12 flat routes (Spatie sai)
================================================================================

TÓM TẮT
─────────
Dọn 12 flat URL có Spatie permission cho action in-meeting — vì action gắn
meeting cụ thể (self-checkin, cast vote, complete speech, ...) nên check qua
khóa ngoại meeting bằng Gate Policy, KHÔNG qua Spatie role-based.

Tất cả 12 endpoint đã có **nested counterpart** từ refactor trước
(`/api/meetings/{meeting}/...`) với Gate Policy đúng → BE chỉ giữ nested.

→ **BREAKING CHANGE** — FE còn gọi flat URL cũ phải migrate sang nested URL.

→ FE cần thêm `{meetingId}` vào path khi gọi. Trong các tab in-meeting, FE đã
biết `meetingId` từ context (URL hoặc store) → migrate đơn giản.


────────────────────────────────────────────────────────────────────────────────
B. FLAT URL GIỮ NGUYÊN (admin CRUD/báo cáo)
────────────────────────────────────────────────────────────────────────────────
GET, POST, PUT, PATCH, DELETE (CRUD chuẩn) + stats + index + show + export +
bulk-delete vẫn dùng flat URL với Spatie permission. Đây là endpoint cho trang
QUẢN TRỊ (admin báo cáo, không phải action trong cuộc họp).

VD vẫn dùng được:
  GET    /api/meeting-attendances?meeting_id=X        // admin xem list điểm danh
  GET    /api/meeting-attendances/stats?meeting_id=X  // dashboard
  GET    /api/meeting-vote-responses?meeting_vote_topic_id=Y
  POST   /api/meeting-discussion-registrations        // admin thêm đăng ký hộ (manual)
  PATCH  /api/meeting-vote-topics/{topic}             // admin sửa tiêu đề topic
  DELETE /api/meeting-vote-topics/bulk-delete         // admin xóa hàng loạt


────────────────────────────────────────────────────────────────────────────────
C. PERMISSION SEEDER — DROP DEAD PERMISSIONS
────────────────────────────────────────────────────────────────────────────────
Đã GỠ khỏi PermissionSeeder + MeetingPermissionSeeder:
  - meeting-attendances.checkin
  - meeting-attendances.markAbsent
  - meeting-attendances.approve
  - meeting-attendances.reject
  - meeting-participants.respond
  - meeting-discussion-registrations.complete

Sau khi `db:seed --class=PermissionSeeder` và `permission:cache-reset` trên
production, các Spatie role không còn có 6 permission này. FE/UI nào còn check
CASL `meeting-attendances.checkin` sẽ luôn return false.

→ FE migrate sang check `current_user_meeting_role` (từ MeetingResource) hoặc
   gọi action qua nested URL và để BE Gate Policy quyết định.
