CHANGE LOG FE — Khung giờ điểm danh + Tái cấu trúc Cấu hình chung
Ngày: 2026-05-11

A. KHUNG GIỜ ĐIỂM DANH (meeting)
================================

Schema: bảng `meetings` thêm 2 cột (datetime, nullable):
  - attendance_open_at   : thời điểm mở điểm danh
  - attendance_close_at  : thời điểm đóng điểm danh
  Null = không giới hạn (cho phép điểm danh bất kỳ lúc nào sau publish).

Form thêm/sửa cuộc họp:
  POST /api/meetings           body thêm: attendance_open_at, attendance_close_at
  PUT  /api/meetings/{id}      body thêm: attendance_open_at, attendance_close_at
  Validate BE: cả 2 nullable, close_at must after_or_equal open_at.

MeetingResource expose:
  "attendance_open_at": "2026-05-15T07:30:00+07:00" | null   (ISO 8601)
  "attendance_close_at": "2026-05-15T08:15:00+07:00" | null

Enforce BE (đại biểu self-action):
  - POST /api/meeting-attendances/checkin          -> 422 nếu now ngoài window
  - POST /api/meeting-attendances/checkin-by-token -> same (gọi qua checkin())
  - POST /api/meeting-attendances/mark-absent      -> same
  - POST /api/meeting-attendances/manual-checkin   -> KHÔNG check window (thư ký luôn pass)

Error message: "Chưa đến giờ điểm danh. Mở lúc HH:mm dd/mm/yyyy."
              "Đã hết giờ điểm danh. Đóng lúc HH:mm dd/mm/yyyy."

FE Tab Chương trình:
  Nút "Điểm danh" / "Báo vắng" CHỈ hiển thị khi:
    now >= attendance_open_at (hoặc open_at null)
    AND now <= attendance_close_at (hoặc close_at null)
  Compute từ resource 2 field ISO trên + Date.now().
  Ngoài window -> ẩn nút, hiển thị thông báo "Mở lúc..." / "Đóng lúc...".

B. XÁC NHẬN THAM GIA / BÁO VẮNG TRƯỚC NGÀY HỌP
==============================================

Endpoint: PATCH /api/meeting-participants/{id}/respond
Body: { response_status: 'accepted' | 'declined', absence_reason?: 'string' }

BE validate mới: now() < meeting.start_time
  -> Sau start_time -> 422 "Cuộc họp đã bắt đầu — không thể cập nhật xác nhận tham gia / báo vắng nữa."
  -> Đại biểu chỉ có thể điểm danh / báo vắng tại chỗ qua endpoint attendance.

FE: ẩn nút "Xác nhận tham gia" / "Báo vắng có lý do" khi now >= meeting.start_time.
