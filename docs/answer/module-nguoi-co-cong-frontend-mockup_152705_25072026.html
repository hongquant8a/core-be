Quy ước chung

Áp cho mọi request trong module

01 Xác thực & Tenant

Mọi request gắn Authorization: Bearer <token> và X-Organization-Id: <id>. Thiếu header tổ chức → 422. Không gửi organization_id trong body — server tự scope.

02 Response & phân trang

Luôn đọc data (không phải root). Danh sách trả mảng data + meta/links. Filter chung: search from_date to_date sort_by sort_order limit page.

03 Enum cho dropdown

Gọi GET /beneficiary-enums một lần, cache lại. Trả beneficiary_type, beneficiary_status, gender, dependent_relationship — mỗi phần tử { value, label }. Không hardcode.

04 Upload file

Giấy tờ & ảnh quyết định gửi bằng multipart/form-data, trường files[] — không nhét trong JSON. Mỗi file ≤ 10MB.

05 Ngày giờ

Gửi ngày dạng Y-m-d. Server trả sẵn định dạng hiển thị: ngày dd/MM/yyyy, giờ HH:mm:ss dd/MM/yyyy.

06 Phân quyền UI

Ẩn/hiện nút theo quyền {resource}.{action} — vd beneficiaries.store, beneficiary-documents.destroy, beneficiary-statistics.view. Backend vẫn chặn 403.

Flow Nhập liệu & file lỗi

Dòng hợp lệ vẫn được nhập; dòng lỗi bỏ qua. Response kèm errors[] (hiển thị inline) và error_file — file Excel base64 (cột STT · Hàng số · Cột · Lỗi · Giá trị) để tải về.

import / export (mỗi resource)
GET/{resource}/import-templateblob .xlsx — có dropdown + dấu * cột bắt buộc
POST/{resource}/importmultipart file → { failed_count, errors[], error_file }
GET/{resource}/exportblob .xlsx — kèm cột quan hệ (Thân nhân; Loại đối tượng…)
// tải file lỗi từ base64
const f = res.data.data.error_file;
if (f) {
  const b = Uint8Array.from(atob(f.base64), c => c.charCodeAt(0));
  const url = URL.createObjectURL(new Blob([b], { type: f.mime }));
  Object.assign(document.createElement('a'), { href: url, download: f.name }).click();
}
Import chỉ gọi 1 lần/file (dòng hợp lệ đã nhập). Liên kết danh mục bằng tên: cột CCCD chủ hộ (tra hộ) và Tổ dân phố (tra theo tên). Ràng buộc tối thiểu — chỉ vài cột chính bắt buộc.
